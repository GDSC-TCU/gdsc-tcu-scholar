## アプリ概要
Google ScholarがCitation順で論文を表示できないためCitation順に表示できるアプリを制作した。

## 環境

scholarly 1.7.11 
flask     2.2.3
## 実行
pythonを実行させてから。windowsを選択

```
pip -r requirment.txt
python query.py
```
